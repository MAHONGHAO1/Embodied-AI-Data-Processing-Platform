# v0.16.1 — 队列可见：运行诊断页直接看任务、取消与重试

**补上 v0.16.0 队列的操作界面，不改后端契约，也不扩大能力边界。**

## 改了什么

- **运行诊断页新增「任务队列」面板**：
  - 显示任务编号、状态、创建时间、结果/错误；
  - 运行中/排队中可直接取消；
  - 失败/已取消可一键重试；
  - 页面在运行诊断视图每 5 秒刷新队列，关闭页面不影响 worker。
- 队列状态文案补齐 `succeeded` / `canceled`，与后端状态一一对应。
- 队列仍由 CLI 提交：`robodata jobs submit --plan ...`；界面只做查看、取消、重试，不提供“随便点一下就跑”的隐式提交。
- 前端单测新增队列面板用例；队列 API 仍由既有 `/api/jobs` 提供。

## 边界

- 界面**不能创建**任务；任务计划仍由 CLI 提交并冻结。
- 队列仍是单机单用户 SQLite、默认并发 1；不是多用户调度。
- 取消仍是协作式：运行中的阶段会在安全检查点停止，已写出的运行目录保留但不登记。
- 本版没有新增 Docker 转换镜像；镜像仍不含 PyTorch/LeRobot 隔离环境。
- 外部复现记录仍为 **0**。
- 旧 tag 不移动；`v0.12.1`、`v0.13.0`、`v0.14.0`、`v0.15.0`、`v0.16.0` 保持原指向。
