03

能证明什么，不能证明什么

两仓文档与发布说明都按这个口径写。把边界写清楚，比把功能说满更有用。

能证明

  • 固定公开样例的逐路质检、官方格式读写与独立验包链路可复现
  • 失败运行不会被登记为可交付产物，源文件哈希处理前后一致
  • 数据来源、回退原因与失效指标在界面和报告中一致呈现
  • 锁定依赖、持续集成与干净克隆安装均可复核

不能证明

  • 验收脚本使用明确标注的模拟审核门禁，不代表人工审核或机器人执行结果
  • 不代表模型训练效果、任务成功率、硬件相机同步或通用数据集适配
  • 基金持仓为虚构合成组合，不连接账户、不执行交易、不提供投资建议
  • 两个服务仅监听本机地址，本页为静态展示，不提供在线交互服务
面试追问时打开哪里
追问证据入口
数据来自哪里？批次总览的固定版本、许可与来源信息；逐项校验见 v0.6.0 验收记录。
多相机如何检查？Episode 浏览器的逐路检查状态，以及验收记录中的视频、帧数与时间映射结果。
转换用了官方格式吗？交付核验的官方 LeRobot 离线加载记录与数据字典；格式读写由官方库完成。
失败时会怎样？运行诊断、失败用例与验收记录中的登记门禁；失败运行不会成为可交付产物。
这证明机器人或模型有效吗？不证明。验收范围是数据读取、逐路检查、格式转换与交付。
04

本地运行

界面本身需要本机启动；本页提供的是无需安装即可核对的入口与证据。

# 具身数据平台（Windows / Python 3.12 / Node.js 24 / uv）
uv sync --locked
cd frontend && npm ci && npm run build && cd ..
.\启动工作台.cmd
# http://127.0.0.1:8765/

# 基金助手（默认离线合成演示）
.\启动基金助手.cmd
# http://127.0.0.1:8766/

具体步骤、首次安装脚本与复现验收命令见两仓 README。旧版 Streamlit 入口保留为回退；历史逐节点截图与 v0.4.0 验收报告见 归档页。
