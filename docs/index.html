快速开始

# 主环境
uv sync --frozen

# HDF5 全流程需要独立转换环境
uv sync --project tools/conversion --frozen
uv run robodata fetch-hdf5

# 启动本地工作台
.\启动工作台.cmd
# 浏览器打开 http://127.0.0.1:8501/

需要 Python 3.12 与 uv。SO-100 样本另需 uv run robodata fetch-sample（约 53 MB）。

边界与未做的事

以下均未在本次交付中实现，不宣称具备。
  • 不训练模型：验证了“数据能被官方库正确加载”，未验证训练效果
  • 不支持通用 HDF5 / MCAP 自动接入，仅固定配置的两个公开数据源
  • 未做多相机硬件同步、自动轨迹修复、逐帧标注
  • 未做大规模吞吐压测，当前为单机单用户、CPU
  • SO-100 暂无业务转换交付适配器
  • 公开样本图片为 H.264 有损，float32 映射非 float64 无损
