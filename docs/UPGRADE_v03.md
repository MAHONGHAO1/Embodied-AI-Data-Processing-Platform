# V0.2 → V0.3 实施与验收路线（历史）

> 本页保留 V0.2／V0.3 的阶段规划，不代表当前开发范围。当前业务流程见 [V0.4 状态](STATUS_v04.md)，旧阶段实际结果见 [V0.2 验收](VALIDATION_v02.md) 与 [V0.3 验收](VALIDATION_v03.md)。

本文列出 V0.2 与 V0.3 的计划范围、实现约束和验收要求，供了解项目演进或参与开发的读者参考。完成情况以对应阶段的验收记录为准。

## V0.2

节点状态与数据问题分开；隐藏协调进程、任务隔离、真实超时终止、持久运行记录和中文日志。新检查真实执行，历史报告显式查看。保留原始与两个数据故障副本，增加明确标注的人为运行超时演示。

## V0.3

在独立 Python 3.12 CPU 环境中，将固定版本 robomimic/test HDF5 中 demo_0–2 的 174 帧转换为官方 LeRobotDataset v3.0，通过官方离线加载和批读取验证后，在主工作台浏览和质检。

状态按来源 eef_pos、eef_quat、gripper_qpos 拼9维，动作7维，相机agentview，20Hz派生时间。源全局统计与实际帧数不一致要记录，不修改原始数据。

## 固定边界

本机单用户；不训练、不部署、不公开公司或用户私有数据；不自动修复轨迹；只声明实测的两种输入配置。应用版本0.3.0和LeRobot格式v3.0分别标记。

## 验收证据

主环境pytest、真实SO-100的5次独立运行、Windows页面操作、HDF5来源SHA256、官方加载结果、数值映射比对、视频偏移与样本抽查，以及下载报告与日志的一致性。
