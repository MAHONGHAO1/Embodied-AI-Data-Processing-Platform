## 当前源码中的流程

| 环节 | 当前行为 | 实现入口 |
| --- | --- | --- |
| 批次导入 | 本地路径／上传的固定 HDF5，或固定 SO-100 目录；复制校验、预览、批次登记后继续基础清洗检查。 | [importing.py](../robodata/importing.py)、[ui_business.py](../robodata/ui_business.py) |
| 清洗与筛选 | 基础检查与人工筛选分为两个节点；完整通过才可保留；隔离／排除需原因并确认候选集。 | [business.py](../robodata/business.py)、[store.py](../robodata_business/store.py) |
| 标注与审核 | 两个独立人工节点；草稿、提交、退回、通过与审计。HDF5 全部保留任务通过后尝试启动自动处理。 | [store.py](../robodata_business/store.py)、[ui_business.py](../robodata/ui_business.py) |
| 最终质检与候选转换 | 审核后复核候选数据、映射及标注，HDF5 通过后继续官方写入、加载、输出质检与打包。 | [business.py](../robodata/business.py)、[worker.py](../tools/conversion/worker.py) |
| 交付验证 | 数据与证据打包，独立解包、哈希检查、官方加载；有效登记后提供下载。 | [delivery.py](../robodata/delivery.py)、[worker.py](../tools/conversion/worker.py) |
| 运行与回写 | 共享后台运行记录；关联批次与版本；证据核对、登记恢复、过期结果保留。 | [business.py](../robodata/business.py)、[ui_runs.py](../robodata/ui_runs.py) |

当前侧栏为五个业务分组（批次管理、清洗筛选、标注审核、转换验证、交付中心）与运行记录，顶部五步进度条可点击跳转，URL 携带 `page` 与 `batch_id`。批次管理页收纳批次总览、上传／导入、任务浏览与来源与字段；转换验证页收纳数据质检、格式转换与质检报告历史。样本数据概览、样本任务浏览、样本质检报告和公开样本转换放入折叠的高级工具。

**八个业务节点不占侧栏入口**，而是在各页面内以「节点执行」状态表呈现，逐条记录执行状态、耗时、结论与文件证据。导航实现见 [ui_navigation.py](../robodata/ui_navigation.py)、[ui_flow.py](../robodata/ui_flow.py)，历史报告见 [ui_report_history.py](../robodata/ui_report_history.py)；应用版本保持 0.4.0。

导入运行在批次登记后继续基础清洗；HDF5 最后一条保留任务审核通过后启动最终质检并自动继续。基础检查、人工审核和最终质检分别记录。自动处理启动失败可在数据质检节点重试；规则未通过或执行失败会停止下游。最新真实自动链和浏览器操作见 [V0.4 实际验收](VALIDATION_v04.md)。

## 数据与操作边界

- **HDF5 配置**：固定 robomimic `test/test.hdf5` 的 demo_0–2；业务候选可保留其中的任务。上传入口仍核验来源与结构，不支持任意 HDF5 自动推断。
- **SO-100 配置**：固定五条公开任务；当前支持导入、基础检查、筛选、标注审核及最终质检，尚无对应的转换交付路径。
- **测试副本**：必须标注注入内容；输入哈希变化如实记录，仍需通过后续检查。不可读文件可以在导入阶段失败，而不是保证每种坏数据都能走到筛选页。
- **清洗与审核**：以整条任务筛选和任务级标注为范围；本地单用户，无自动轨迹修复或多人权限系统。
- **结果失效**：管理副本变化需重新导入；业务内容变化使旧产物变为历史；未完成验证或包哈希变化不能作为当前有效交付。
- **任务结果**：人工标注的成功／失败与数据质量、程序执行状态独立；没有自动任务成功率评估。
