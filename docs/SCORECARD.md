## 证据标准

一条主张只有同时满足下面三条，才允许写进 README 首屏：

1. 有一条可以复制执行的命令。
2. 有一次原始 JSON / HTML / ZIP 证据，链接可直接打开。
3. 有一句明确的「这不证明什么」。

不满足的，降级为「计划」或删除。

## 本周期非目标

- 不做多租户、登录、云部署或公网服务。
- 不做真实交易、券商账户或投资收益承诺。
- 不宣称策略训练成功率、硬件同步或真实机器人执行安全。
- 不宣称 100 万行表格检查等于 100 万行端到端转换。
- 不为了让页面「看起来完整」增加空壳功能。
- 不把 Fund Lens 扩成第二个旗舰；它只验证同一套来源追踪方法能否迁移。
