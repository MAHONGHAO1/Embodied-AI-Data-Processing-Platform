# 导航验收记录

验收日期：2026-09-11。环境为 Windows、Python 3.12、CPU、本地单用户。应用版本 `0.4.0`。
验收方式：启动本机 Streamlit 服务（`http://127.0.0.1:8501/`），用无头 Edge 实际打开页面逐项核对，并运行页面测试。

## 验收结论

侧栏为**八个业务节点＋批次总览＋运行记录**，与具身数据交付的标准流程一致：

```text
批次总览
上传／导入 → 数据清洗 → 数据筛选 → 数据标注
          → 标注审核 → 数据质检 → 格式转换 → 打包交付
运行记录
```

顶部进度条为同样的八个节点，可直接点击跳转。页面地址携带 `page` 与 `batch_id`，可分享并复现到具体节点页面。
「任务浏览」「来源与字段」收纳在批次总览页的页面内导航；「质检报告」收纳在数据质检页的页面内导航。
独立样本浏览、故障演示与公开样本转换收纳在折叠的**高级工具**。

## 变更说明

修改前侧栏为五个业务分组（批次管理／清洗筛选／标注审核／转换验证／交付中心），八个业务节点不占侧栏入口，只在页面内以状态表呈现。
八个节点的页面实现一直存在，本次改动恢复其侧栏入口，并把页面标题、进度条、按钮文案统一到八节点口径。

| 文件 | 改动 |
| --- | --- |
| `robodata/ui_navigation.py` | 新增 `NODE_ORDER`、`MAIN_OPTIONS`、`SUB_ROUTES`、`main_label()`、`main_for()`；主导航由五个分组改为九个业务页面＋运行记录；保留旧五分组常量作为兼容别名 |
| `robodata/ui_flow.py` | 进度条改为八个节点；页面标题与当前阶段显示改用节点名 |
| `robodata/ui_business.py` | 「前往转换验证」等按钮文案改为八节点名称 |
| `tests/test_navigation.py`、`tests/test_app.py`、`tests/test_business_app.py` | 断言改为八节点口径 |
