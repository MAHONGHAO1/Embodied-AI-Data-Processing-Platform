# V0.5.0 版本状态与范围

应用版本：`0.5.0`。运行环境：Windows / Python 3.12 / CPU / 本地单用户。

## 工作台流程

HDF5 与固定版本 SO-100 数据均可经工作台 UI 导入、清洗、筛选、标注审核和最终质检。最后一条保留任务审核通过后，工作台启动后台运行记录并继续转换、输出质检、打包和独立验包。页面显示阶段状态、日志、诊断及登记证据。

SO-100 输入为 LeRobot v2.0。转换器先在管理副本上补 v2.1 episode 统计，再调用官方阶段函数写入 v3.0；官方整库转换会替换源目录，因此本工具只转换管理副本。内容版本、文件哈希或交付包验证不匹配时，结果保留为历史或失败，不提供为当前交付。

## 边界

- 默认 SO-100 子集 Episode 0–4，共 3,562 帧；可用 `ROBODATA_SO100_EPISODES` 调整范围。
- 仅处理数据结构、数值、官方加载和交付包可读性；不评估机器人执行成功率、物理安全或模型训练效果。
- 不包含通用 MCAP、轨迹自动修复、多用户权限或公开在线交互服务。
